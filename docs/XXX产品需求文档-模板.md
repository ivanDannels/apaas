# 一、 简介

 本文档主要定义读书人频道的功能详细描述和前端页面的各个模块的内容和逻辑。

## 1、    目的

此文档的目的主要是清晰、有层次的定义页面原型中各个模块的内容来源和相关的逻辑。

## 2、    范围

此文档主要描述读书人频道中前端页面涉及到的功能点、相对应的后台管理功能支持、以及部分交互细节。本文档主要读者为技术部门的前端工程师，以及视觉部门的视觉设计。

A.    我的书架

D.    图书馆

H.    创建读书会活动、参加活动、关注活动

2.2   同城读书会：用户登录后从WOYO世界的用户填写的个人信息中获取用户所在城市信息，如无此信息，从登录IP判断，如无法读取，默认显示上海同城读书会信息，用户可切换城市，并记录最后切换的城市为用户所在城市信息。如同城读书会未覆盖用户所在城市，首页读书会活动信息全部显示在线活动，读书会活动版块的同城活动默认显示上海同城读书会信息，可切换城市。

2.3   查看他人书架：通过个人空间点击书架进入

用户查看他人书架可浏览的信息包括：

书籍：订阅、收藏

视频：订阅、收藏

书友

读书会活动：参加、关注、历史记录

书评:长篇大论、三言两语、阅读批注

创作：作品集

# 五、 其它产品需求

## 1、    性能需求

前端阅读页面的阅读体验，需要滚动流畅，滚动阅读时不停顿。

展示批注数据的时候需要即时展示，不可以感受到明显的后台查询过程。

后台动态推送最新活动和最新话题到前台的ajax气泡效果，不可导致浏览器进程假死。
